01 · Pole Placement

Decide exactly where the poles go — then compute the gain that puts them there.

Instead of picking a gain and seeing where the poles land, pole placement works backwards: choose a desired pair of closed-loop poles, σ ± jω, directly — they set exactly how fast the response decays (σ) and how much it rings on the way there (ω) — then solve for the state-feedback gain vector that puts them exactly there (Ackermann's formula, if the system is controllable). This only works if the system is controllable in the first place — checked via the rank of the controllability matrix, [B AB A²B ... ].

Stable. Both poles sit left of the imaginary axis, so the response decays as t→∞. The further left, the faster it dies out; the closer to the real axis, the less it oscillates on the way there.
Before attempting pole placement on a real system, what must be checked first?
If the controllability matrix doesn't have full rank, there is genuinely no gain vector — no matter how cleverly chosen — that can move the poles wherever you like. Controllability is the precondition, not a formality.
02 · Lyapunov Stability

Prove stability without ever solving the equations of motion.

Sometimes a system is too nonlinear to get a clean pole-location answer at all. Lyapunov's method sidesteps solving the dynamics entirely: find a scalar "energy-like" function V(x) that's positive everywhere except zero at the equilibrium, and show that its rate of change V̇(x) is always negative along the system's trajectories. If both hold, the system is provably stable — full stop — without ever writing down what x(t) actually equals. It's the mathematical version of proving a ball must eventually stop rolling by showing its height keeps decreasing, without tracking its exact path down the hill.

V(x) > 0, V(0) = 0   and   V̇(x) < 0 → asymptotically stablethe two conditions a valid Lyapunov function must satisfy
Why this matters beyond the exam: Lyapunov's method is one of very few tools that works on genuinely nonlinear systems where linearization (and therefore pole placement) breaks down or only applies locally near one operating point.
What is the core advantage of Lyapunov's method over pole-placement-style analysis?
Pole placement fundamentally relies on linear (or linearized) system models. Lyapunov's method makes no such assumption — which is exactly why it remains a core nonlinear-control tool.
03 · The Exam Toolkit

The formulas worth having cold.

Ackermann's Formula
Computes the state-feedback gain K that places closed-loop poles exactly at a chosen set of locations, given a controllable (A,B) pair.
Controllability Matrix
[B AB A²B ... Aⁿ⁻¹B] — full rank means every state can be driven anywhere via the input; pole placement is only valid if this holds.
Observability Matrix
The dual concept: full rank means the internal states can be reconstructed purely from the output — required before you can even build a state estimator.
Describing Functions
An approximate frequency-domain technique for predicting limit cycles in systems with genuine nonlinearities like saturation or backlash.
Lead-Lag Compensation
A lead network adds phase (speeds response, improves stability margin); a lag network trades speed for improved steady-state accuracy.
