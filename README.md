# From Rock to Radio: The Electronics Bible

A complete interactive guide to electronics, from first principles to advanced theory. Built for hobbyists and engineers alike.

## Overview

This repository contains a single, self-contained HTML file with **24 interactive chapters** covering:

- **Part I: Foundations** (1.1–1.6): Electricity, charge, magnetism, induction, semiconductors
- **Part II: AC/DC** (2.1–2.3): DC vs AC, RLC circuits, power conversion
- **Part III: Components & Devices** (3.2–3.4): Diodes, transistors, op-amps, supporting components
- **Part IV: Digital & Microcontrollers** (4.1–4.7): Logic, CPU architecture, memory, GPIO, communication protocols
- **Part V: Advanced Theory** (5.1–5.7): Control systems, digital design, embedded processors, secure hardware, nanoelectronics


## Live Demo

The site is hosted on GitHub Pages at:

## How to Use

1. Open `index.html` in any modern browser
2. Use the sidebar to navigate between chapters
3. On mobile, tap the ☰ hamburger menu
4. Each chapter includes interactive simulations, sliders, and quizzes
